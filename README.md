# Süper Kolaj

Sınırsız sayıda fotoğrafı tek bir kareye kolaj yapan Android uygulaması.

- Fotoğraf seçiminde sınır yok; tekrar tekrar ekleyebilir, bir klasörün tamamını (alt klasörlerle) tek seferde ekleyebilirsin.
- Galeriden "Paylaş" menüsüyle de fotoğraf gönderebilirsin.
- Oran (1:1, 4:5, 9:16, 16:9, 4:3, A4), çıktı boyutu (2048–8192 px), arka plan rengi, boşluk ve karıştırma seçenekleri.
- Kolaj galeriye `Resimler/SuperKolaj` klasörüne kaydedilir, doğrudan paylaşılabilir.

APK, her push'ta GitHub Actions ile derlenir ve **Releases** sayfasına `SuperKolaj.apk` olarak yüklenir.
